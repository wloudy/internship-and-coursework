# Учёт опоздавших студентов

Информационная система для учебной практики и курсовой работы. Программа имитирует события турникета и автоматически заносит в журнал опоздавших студентов 1–2 курсов после начала первой пары. По умолчанию начало пары — 09:00.

В демонстрационных данных есть группы ИС-26 (1 курс), ИС2-25 (2 курс) и ИС1-24 (3 курс), а также два преподавателя. Преподаватели и студенты 3 курса отображаются в ленте и в CSV как «Прошёл», без записи об опоздании.

## Требования

- Python 3.10+
- Windows / Linux / macOS

## Установка и запуск

```powershell
git clone https://github.com/wloudy/internship-and-coursework.git
cd internship-and-coursework
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5051

При первом запуске создаётся файл `late_students.db` с тестовыми людьми.

## Тесты

```powershell
python test_rules.py
```
